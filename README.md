This game is a version of snek if it was a rhythm game, you move around with your W, A, S and D keys to the beat, and instead of eating appels your try to wrap around them. Running into the walls and appels will kill you, so make sure not to do that.

If you want to play it, do so at this link https://omeletted.itch.io/snek, or you can compile it in the godot engine whatever way you like.
